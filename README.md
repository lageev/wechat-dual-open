# WeChat Dual-Open Manager

macOS 微信双开管理工具，一条命令实现微信多开。

## 快速开始

```bash
# 克隆仓库
git clone git@github.com:lageev/wechat-dual-open.git
cd wechat-dual-open

# 添加执行权限
chmod +x wechat-dual.sh

# 运行
./wechat-dual.sh
```

## 功能说明

脚本启动后会显示交互菜单：

```
  请选择操作:

  1) 安装双开     首次使用，复制并配置双开微信
  2) 更新双开     微信更新后，重新复制并配置
  3) 重新签名     仅重新签名（微信更新后的快捷方式）
  4) 查看状态     检查双开微信当前状态
  5) 卸载双开     删除双开微信
  0) 退出
```

### 1) 安装双开

首次使用，执行完整的三步配置：

1. 复制 `WeChat.app` 为双开应用
2. 修改 `CFBundleIdentifier` 避免进程冲突
3. 重新签名应用绕过系统验证

安装时可以自定义双开应用的名称，直接回车则使用默认名称 `wechat2`：

```
为双开微信取个名字（直接回车使用默认名称 wechat2）:
```

例如输入 `wechat-work`，将会创建 `/Applications/wechat-work.app`。

### 2) 更新双开

当微信 App Store 更新后，双开应用版本会落后。选择此项会删除旧的双开应用，重新从最新版微信复制并配置。

### 3) 重新签名

微信更新后的快捷修复方式，仅执行修改标识符和签名两步，无需重新复制。

### 4) 查看状态

显示原版微信和双开微信的版本号、Bundle ID、代码签名状态，方便排查问题。

### 5) 卸载双开

删除双开应用，会二次确认后才执行。

## 实现原理

macOS 通过 `CFBundleIdentifier` 识别应用，同一个标识符只能运行一个实例。本工具通过以下方式实现双开：

1. **复制应用** — 将 `WeChat.app` 完整复制一份
2. **修改标识符** — 将副本的 `CFBundleIdentifier` 改为不同的值（如 `com.fring.wechat`）
3. **重新签名** — 修改后的应用签名失效，需要重新签名才能正常运行

## 配置文件

双开应用名称保存在 `~/.wechat-dual.conf` 中，后续操作（更新、签名、卸载）会自动读取，无需重复输入。

## 注意事项

- 需要 `sudo` 权限（复制和签名系统应用目录）
- 微信更新后需要重新执行「更新双开」或「重新签名」
- 双开应用与原版微信共享相同的沙盒数据目录
